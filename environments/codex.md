Codex docs here. The first trial of `guide.md` is Codex on Windows

From a research report made for this guide (2026-11-09), citing the
Codex docs of 2026:

- Codex has an OS sandbox and an approval policy. New users get
  workspace-write in a git folder and read-only elsewhere.
- Permission profiles (Beta): read, write and deny levels; built-in
  read-only, workspace and full access; the docs say to set the default
  explicitly.
- Its hooks are "not a complete enforcement boundary" (the docs, as
  quoted there).
- No guided set-up or interview is recorded.

From earlier notes made here: Codex reads a home `AGENTS.md`
(`~/.codex/AGENTS.md`) and has hooks of its own.

Not known here: where Codex keeps its settings on Windows and how they
are written; whether its sandbox runs on native Windows; how its
permission rules match paths and commands; how a project's own Codex
settings combine with a user's; where its login is stored.
